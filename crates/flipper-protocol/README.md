# flipper-companion-protocol

Serial framing, protobuf RPC session and screen conversion for the Flipper Zero.

This crate is part of the [flipper-companion](https://github.com/zx97/flipper-companion) workspace. The desktop and command-line binaries are `flipper-companion` and `flipper`.
