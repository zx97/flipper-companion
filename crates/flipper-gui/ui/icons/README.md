# Icons

These SVGs are taken from the **Breeze** icon theme (KDE), `breeze-dark`
variant, version shipped with the system used for development.

- Upstream: https://invent.kde.org/frameworks/breeze-icons
- License: GNU Lesser General Public License v3.0 or later (LGPL-3.0-or-later)

They are vendored unmodified so the application builds without an icon theme
installed.  The icons are monochrome; the UI colorizes them at runtime so they
follow the theme (grey for idle controls, Flipper orange for the active tab).
