# flipper-companion

Desktop companion for the Flipper Zero: device management, firmware updates, file browser, live screen mirroring with a remote keypad, backups and a Flipper application catalog that installs and updates apps on the SD card.

This crate is part of the [flipper-companion](https://github.com/zx97/flipper-companion) workspace. The desktop and command-line binaries are `flipper-companion` and `flipper`.
